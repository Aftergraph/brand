# Architecture Visual Grammar

An Aftergraph diagram remains recognizable without its logo because meaning is carried by consistent geometry.

- Hexagon: bounded institution or mission.
- Circle: principal, human, or agent identity.
- Rounded rectangle: service/tool/runtime.
- Diamond: verifier or consequential gate.
- Document notch: evidence or receipt.
- Cylinder: durable state.
- Solid arrow: authorized execution.
- Violet arrow: delegated authority.
- Teal arrow: evidence/provenance.
- Broken red arrow: revoked path.
- Dashed amber arrow: stale or proposed relation.

Every diagram includes a title, scope, source revision, date/evidence cut, and a prose/table alternative. Generated primitives are in `architecture/primitives/`; diagram topology remains owned by the repository whose architecture is depicted.
