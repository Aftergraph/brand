# STEWARD Product Extension

STEWARD is an Aftergraph product identity and interface projection for a persistent governed intelligence system.

## Locked identity

- Product name: STEWARD
- Parent: Aftergraph
- Palette: Custody & Cream
- Display type: Sora
- Interface type: Manrope
- Mark: Bounded Node, open custody ring with a copper node
- Character: one node entity across roles and states

## Product boundary

STEWARD may visualize missions, roles, state, evidence and verification progress. Those visuals do not own or upgrade canonical truth.

Authority remains with AIE. Policy enforcement remains with Trust Gateway. Durable work remains with WORKS. Runtime lifecycle remains with Aftergraph Runtime. Independent verification remains with Sentinel.

## Assets

- `identity/bounded-node.svg`: canonical product identity mark.
- `tokens.json`: product-scoped Custody & Cream palette.
- `CHARACTER-LAW.md`: immutable character and state rules.
- `motion/presence-contract.json`: semantic motion and accessibility contract.
- `motion/steward-presence.lottie.json`: portable Lottie presence signal with 12 named state markers.
- `3d/reference-model.evidence.json`: evidence for the deterministic 3D reference build.
- `3d/generated-candidates.json`: generated 3D candidates, explicitly non-canonical until reviewed.

## Claim discipline

Presence is not authority. Animation is not evidence. A successful-looking state must not be shown as verified unless a real verification verdict supports it.
